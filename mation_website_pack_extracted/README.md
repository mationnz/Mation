# Mation Website Content & Design Pack

This zip contains a complete, build-ready blueprint for **Mation** (industry-agnostic, **Platform + Services**),
including:

- Full page-by-page copy (headlines, sections, microcopy, CTAs)
- Sitemap + conversion funnel
- Design system (tokens, typography, layout, component standards)
- Interactive widgets + animation storyboards (state-of-the-art, non-gimmicky)
- Developer handoff specs (Next.js structure, component inventory, UI spec schema)
- SEO + analytics tracking plan
- CMS content models + starter resource plan
- Brand assets copied into `/assets/`

## Quick start

1) Start with: `docs/00_overview.md`  
2) Page copy lives in: `docs/pages/`  
3) Design system lives in: `docs/design/` + `docs/design/tokens.css`  
4) Widget specs live in: `docs/interactions/`  
5) Demo UI states (for the hero "Prompt → Canvas" widget) live in: `demo/ui_states/`
