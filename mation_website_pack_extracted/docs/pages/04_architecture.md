### 2) The core model (diagram)

**Title:** Agent Harness + User Harness = Generative Interface

Explain in 5 bullets:
- Orchestrator interprets intent and routes work
- Specialized agents handle retrieval, UI composition, and actions
- UI composer returns a typed UI spec (server-driven UI)
- Frontend renders trusted components from a registry
- Tool gateway enforces permissions + logs everything

Include interactive Architecture Explorer widget.

---

### 3) Server-driven UI

**Title:** Stop shipping 100 pages. Start generating the right UI.  
**Copy:** Instead of hardcoding screens for every workflow, Mation returns a UI schema and renders from a controlled component library. Faster iteration, consistent UX, less clutter.

---

### 4) Memory + context management

**Title:** Built to avoid context rot at scale.  
**Copy:** Separate session memory, task memory, retrieval memory, and structured memory so complex workflows don’t pollute the system and accuracy stays high.

---

### 5) Governed execution

**Title:** Read-only first. Approval-gated actions next.  
**Copy:** High-risk actions require explicit approval. Every action is logged with evidence references. Observability shows reliability, cost, and latency.
