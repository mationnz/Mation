# Accessibility requirements (WCAG AA)

## Must-have

- Contrast meets WCAG AA
- Keyboard navigation for all interactive widgets
- Visible focus states
- Skip-to-content link
- Reduced motion mode supported
- Form errors announced (ARIA)
- Proper alt text for all images

## Widget-specific

### Prompt → Canvas demo
- Provide non-animated fallback state
- Ensure screen reader can parse the prompt picker and “rendered” components

### Architecture explorer
- Nodes must be reachable by keyboard
- Node detail panel must be readable and closable without mouse
