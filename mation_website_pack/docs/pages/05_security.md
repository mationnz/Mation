# Security page

## SEO

- **Meta title:** Security — Governed, auditable AI with Mation

- **Meta description:** Mation is built for enterprise deployment with access control, approval gates, audit trails, and a secure tool gateway for integrations.


---

## Page goal

Reduce perceived risk and give IT a path to deployment.


---

## Layout + copy


### 1) Hero

**H1:** Designed for trust from day one.  
**Sub:** AI is only useful if it’s deployable. Deployable means governed.

CTA: Talk to an architect

---

### 2) Security pillars (5 cards)

1) Access control — RBAC, least privilege, tenant boundaries  
2) Data handling — redaction, retention, controlled storage  
3) Audit trails — who/what/when/why with evidence references  
4) Tool gateway — one chokepoint for integrations and logging  
5) Execution safety — approvals, dry runs, policy enforcement

---

### 3) Governed action simulator widget

Show how an action is handled:
- permission check
- evidence sources
- approval requirement
- audit log entry

---

### 4) Deployment approach (platform + services)

Describe options:
- Start read-only with limited connectors
- Expand capabilities with approval gates
- Harden observability and audit coverage
- Scale to more workflows and teams

---

### 5) Security FAQ

- Can we run read-only first? **Yes.**
- Can actions require approval? **Yes.**
- Can we restrict which systems are reachable? **Yes.**
- Can we log everything? **Yes.**

CTA band: Talk to an architect / Book a demo
