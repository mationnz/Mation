# Animation storyboards (Lottie/Rive/SVG)

## Global motion principles

- Subtle, premium motion (cockpit feel)
- No “AI magic sparkles”
- Must respect reduced-motion settings

## Animation 1 — Canvas expansion (Hero)

**Trigger:** after user selects a prompt  
**Duration:** 450–650ms  
**Motion:** chat compresses to corner → canvas slides in → grid fades up

## Animation 2 — Component assembly (Hero + Product)

**Trigger:** canvas opens  
**Duration:** 600–900ms total (staggered)  
**Sequence:** KPI card → summary → table → chart → artifact editor → action bar

## Animation 3 — Data flow lines (Architecture diagram)

**Trigger:** on scroll into view  
**Duration:** continuous loop, very subtle  
**Motion:** low-opacity gradient line moving left-to-right along connectors

## Animation 4 — Evidence badge pulse

**Trigger:** when outputs load  
**Duration:** 200ms pulse  
**Purpose:** draw attention to “evidence-backed” without being loud
